# Stress API

Stress API is a modular, backend-only API load testing engine built with FastAPI and Python. It serves as the foundational load execution engine for the full-scale final year project, **LoadSync AI** — an intelligent system for autonomous API performance testing, test generation, and optimization.

## Overview

Stress API allows developers and researchers to simulate high-concurrency API traffic and monitor performance metrics such as response times, throughput, success rate, and error distribution. It is designed to be lightweight, extensible, and easily integrable with higher-level agentic systems being developed as part of LoadSync AI.

While this service is not a full-featured testing tool on its own, it plays a critical role in the LoadSync AI architecture by executing test plans generated by intelligent agents and returning structured metrics for evaluation.

## Key Features

- Basic REST API load testing via FastAPI endpoints
- Configurable parameters:
  - HTTP method, headers, request body, delay, concurrency, request count
- Performance metrics:
  - Average response time, error count, throughput, latency distribution
- JSON output reports for downstream analysis
- Modular, async-first design with `httpx` and `asyncio`
- Built for seamless integration with autonomous agents and orchestration layers
